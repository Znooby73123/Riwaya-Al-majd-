# Riwaya Al-Majd

**Riwaya Al-Majd** is an interactive web-based educational game designed to make learning about Saudi Arabia’s history more engaging through quizzes and interactive gameplay.

## Features
- Interactive history quiz with questions, hints, and answer feedback.
- Responsive web interfaces with animations and navigation.
- Contact Us and survey pages.
- Video and collaboration pages.
- Database integration using PHP and MySQL.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Type
Academic Team Project – Web Development Course

## Purpose
To combine web development technologies with interactive learning and promote awareness of Saudi Arabia’s history and heritage.
